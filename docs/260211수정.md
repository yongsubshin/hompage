1. [Critical] 페이지 전환 시 콘텐츠가 안 보이는 렌더링 버그
증상: 메인(/) 에서 다른 페이지로 이동하면 히어로 섹션 텍스트와 카드가 거의 투명하게 렌더링된다. 스크롤을 내렸다 올리면 그때서야 정상 표시된다.
재현 방법:

https://web.popcornsar.com/ 접속
상단 메뉴에서 COMPANY 클릭
→ "About Us" 텍스트, 카드(Mission/Innovation 등)가 거의 안 보임
스크롤 다운 후 다시 스크롤 업 → 그제야 정상 표시

발생 페이지: /company, /products, /company/contact, /company/notice (1차 점검 때는 /company만이었으나 범위 확대됨)
원인 추정: 스크롤 기반 fade-in 애니메이션(Intersection Observer 또는 scroll trigger)의 초기 상태가 opacity: 0으로 설정되어 있고, 페이지 전환(Next.js 클라이언트 라우팅) 시 스크롤 위치가 top이라 뷰포트 안에 있는 요소들의 애니메이션이 트리거되지 않는 것으로 보임.
수정 방법:

히어로 섹션(뷰포트 최상단에 위치하는 요소)은 스크롤 애니메이션 대상에서 제외하거나, 초기 opacity: 1로 설정
또는 페이지 전환 시 Intersection Observer를 재초기화하여 이미 뷰포트에 있는 요소를 즉시 visible 처리
Next.js의 useEffect에서 페이지 마운트 시 뷰포트 내 요소를 강제로 animate-in 처리
